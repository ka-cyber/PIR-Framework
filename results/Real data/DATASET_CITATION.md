# Dataset attribution

Jezewski J, Matonia A, Kupka T, Roj D, Czabanski R. Determination of the fetal heart rate from abdominal signals: evaluation of beat-to-beat accuracy in relation to the direct fetal electrocardiogram. *Biomedical Engineering/Biomedizinische Technik*. 2012;57(5):383–394. https://doi.org/10.1515/bmt-2011-0130.

Dataset: PhysioNet Abdominal and Direct Fetal ECG Database, version 1.0.0. https://doi.org/10.13026/C2RP4B. It contains five-minute multichannel recordings from five women in labor; each record has four abdominal ECG signals and a simultaneous direct fetal ECG reference with cardiologist-verified R-wave markers. Sampling frequency is 1 kHz. The dataset is ECG-only; it contains no PPG.

The supplied archive's `SHA256SUMS.txt` was checked against the extracted dataset files; all listed files passed.

When reusing the dataset, comply with its Open Data Commons Attribution License v1.0 and cite both the dataset and original paper.
